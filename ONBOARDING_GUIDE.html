New Client Configuration Guide

Ready to track a new client?

Follow these 4 steps to add a client to the automated tracking system.

1

Open the Master Config Sheet

All system settings are managed through your central Google Sheet. Open it to begin.

https://docs.google.com/spreadsheets/d/1zSbn-poFSY512rIPN45a3yhCG7P5sDaXdu_JLoequUI/
2

Add the Client Details

Add a new row at the bottom with the following information:

client_name Required

The human-readable name (e.g., Acme Plumbing). Used in email reports and to verify lead sources.

status Required

Set to active to process leads. Set to retired to pause the agent for this client.

report_recipient Required

Who gets the report. Separate multiple emails with a comma.
Tip: Use bcc: prefix (e.g., admin@netgain.agency, bcc:internal@netgain.agency) to hide recipients from the client.

sheet_url Required

The link to the client's destination Lead Sheet. The agent logs all data here.

search_keywords Required

Terms the agent uses to find leads in Gmail (e.g., "New Lead, Call Tracking").

client_id Optional

A unique technical slug (e.g. acme_plumbing). Helpful for organizing system logs.

parser_settings Optional

Used to ignore specific test emails. Example: {"ignored_emails": ["test@test.com"]}

3

Set Up the Client's Lead Sheet

Ensure the client's destination sheet has the correct headers in the first row. The agent will add them automatically if missing, but it's best to verify.

Date | Client Name | Email | Phone | Platform | Lead Type | Sold? | Revenue | Notes
4

Grant Access to the Lead Agent

You must share the client's lead sheet with the robot service account email for it to work:

burak-18@gen-lang-client-0007285386.iam.gserviceaccount.com

(Click share in Google Sheets, paste the email, and choose Editor)

Once complete, the agent will automatically find this client next time it runs.
